# 档案交接演练包（2026-11-23）

维修换管场景下，如何依据《器材交接表》的物理身份生效区间，区分可跨档沿用的音管、
只能证明单场读数的旧证据，以及必须用换管后录音重建的稳定性。

## 目录

- `档案交接手册.md` —— 主手册：规则、陷阱演练、发布分级、操作流程与检查清单
- `器材交接表.json` —— 物理身份生效区间台账（身份权威来源，系统外部证据）
- `原始包/`
  - `甲-维修前基础包.json`、`乙-维修前复核包.json`
  - `丙-换管后基础包.json`、`丁-换管后复核包.json`
  - `身份交叉表.json` —— 槽位×物理身份×封存证据交叉表（含摘要前缀）
- `复算/`
  - `复算脚本.py` —— 独立重算物理量与摘要，并与真实工作台对账、演练封存/篡改/非法输入
  - `复算报告.json`、`复算摘要.txt` —— 62 项核对全部通过的结果
  - `封存包-*.json` —— 四个完整封存包副本
  - `封存台账.json`、`篡改核对.json`、`身份交叉表-含完整摘要.json`
- `临时归档/` —— 占位目录；演练使用临时库，运行结束不保留数据库

## 一句话结论

- **换管槽**：甲/丙两包该槽位 8 个阶段报表行逐行相同、摘要各自有效，但物理音管已由
  P-017 换为 P-204，旧调律承诺禁止沿用；新管稳定性由丁包两条换管后录音重建（极差 2.595 音分）。
- **沿用槽**：P-018 身份连续、见证齐全，乙包承诺可跨档沿用，漂移 0.0→4.035 音分登记备查。
- **无凭槽**：无身份见证，前后偏差 0.0→2.307 音分虽接近，最高只能发布 L1 单场读数，
  乙/丁两包 handoff 均为 pending。

## 复算方式

```sh
python3 -I handoff-drill-20261123/复算/复算脚本.py \
  handoff-drill-20261123/原始包 \
  handoff-drill-20261123/复算 \
  /workspace
```

本演练不修改系统代码与原始包；篡改核对仅作用于内存副本。
